# Born of the Spirit and Truth

A Spirit filled Christian book experience written by Bradley Hobbs.

Live Website: Born of the Spirit and Truth Website

## Overview

Born of the Spirit and Truth is an immersive digital book designed to guide readers into a deeper understanding of:

- The Holy Ghost
- The Oneness of Jesus
- Spirit baptism
- Spiritual discernment
- Grace and accountability
- Daily Spirit led living
- Assurance and rest in Jesus

The website presents the complete manuscript through a cinematic reading experience using elegant typography, immersive visuals, smooth scrolling, and responsive design for desktop and mobile readers.

## Features

- Fully responsive design
- Modern glassmorphism inspired interface
- Individual chapter pages
- Animated reading experience
- Custom banner imagery
- Progress indicators for reading
- Dedicated reflection and purpose pages
- Custom 404 page
- Reusable footer include
- Optimized for GitHub Pages hosting
